# FEDORA

## Package Management (Fedora-Specific)
```bash
#1. Check for and install system and app updates
sudo dnf update	

#2. Install a new application or package
sudo dnf install <package>	

#3. Uninstall a package
sudo dnf remove <package> 

#4. Search repositories for a specific package
dnf search <keyword> 

#5. Clean up unused dependencies left behind
sudo dnf autoremove	
```
